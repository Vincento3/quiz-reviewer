1. Algebra

Quadratic equations and Viète's formulas

A quadratic equation has the form ax² + bx + c = 0, with a ≠ 0. The roots are found using the quadratic formula:

x = (-b ± √(b² - 4ac)) / 2a

The discriminant D = b² - 4ac tells the nature of the roots: if D > 0, there are two real roots; if D = 0, one repeated root; if D < 0, no real roots.

Viète's formulas relate the roots r₁ and r₂ to the coefficients:

r₁ + r₂ = -(b / a) and r₁r₂ = c / a

Arithmetic sequences and series

An arithmetic sequence adds the same constant d each time. If the first term is a₁, then the nth term is:

a_n = a₁ + (n - 1)d

The sum of the first n terms is:

S_n = n/2 (a₁ + a_n) = n/2 [2a₁ + (n - 1)d]

Use the common difference to identify missing terms and to find the total quickly.

Logarithms and solving exponential equations

A logarithm answers the question: “What exponent gives this value?” If b^x = y, then x = log_b(y).

log_b(xy) = log_b x + log_b y
log_b(x / y) = log_b x - log_b y
log_b(x^n) = n log_b x

To solve exponential equations, rewrite both sides with the same base or take logs. Example: 2^x = 16 means x = 4 because 2⁴ = 16.

Absolute value equations

The absolute value of a number is its distance from zero. Therefore, |x| = a means x = a or x = -a, as long as a ≥ 0.

For equations like |2x - 5| = 9, split into two cases:

2x - 5 = 9 or 2x - 5 = -9

Solve both equations separately and check the solutions in the original equation.

Polynomial Remainder Theorem

If a polynomial P(x) is divided by x - a, the remainder is P(a). This is the Remainder Theorem.

If P(a) = 0, then x - a is a factor of the polynomial. This also gives a quick way to test whether a number is a root.

Work and rate word problems

Rate problems depend on how much work is done per unit of time. If one person completes a job in t hours, their rate is:

rate = 1 / t

For combined work, add rates:

1 / t₁ + 1 / t₂ + ... = 1 / T

Where T is the combined time to finish the whole job. Use careful units and convert all rates to “job per hour” or “job per minute.”

2. Geometry

Interior angles of regular polygons

The sum of the interior angles of an n-sided polygon is:

(n - 2)180°

For a regular polygon, each interior angle is:

((n - 2)180°) / n

Example: A regular hexagon has each interior angle of 120° because (6 - 2)180 / 6 = 120.

Similar triangles and area ratios

Two triangles are similar if their corresponding angles are equal and their sides are proportional. For similar triangles, the ratio of corresponding sides is constant.

If the similarity ratio is k, then the ratio of corresponding areas is k².

A₁ / A₂ = (s₁ / s₂)²

This is a useful shortcut in scale drawings, maps, and comparison problems.

Right triangle properties (altitude, legs, and hypotenuse)

In a right triangle, the side opposite the right angle is the hypotenuse. The other two sides are the legs. The Pythagorean Theorem states:

a² + b² = c²

If an altitude is drawn to the hypotenuse, it creates two smaller right triangles that are similar to the original triangle. This makes it possible to derive relationships among the segments of the hypotenuse, the altitude, and the legs.

3. Trigonometry

Circular function and the unit circle

A unit circle has center at the origin and radius 1. Any angle θ on the unit circle has coordinates (cos θ, sin θ).

This relationship connects angles and coordinates and is essential for solving trig problems quickly and accurately. The angle is measured from the positive x-axis.

Trigonometric functions across different quadrants

The signs of sine, cosine, and tangent depend on the quadrant:

  • Quadrant I: all positive
  • Quadrant II: sine positive
  • Quadrant III: tangent positive
  • Quadrant IV: cosine positive

Reference angles help determine values in any quadrant by using the acute angle with the x-axis.

Fundamental trigonometric identities

Core identities include:

sin²θ + cos²θ = 1
tan θ = sin θ / cos θ
sec θ = 1 / cos θ
csc θ = 1 / sin θ
cot θ = 1 / tan θ

These identities allow you to simplify expressions, prove equations, and solve trig equations.

Solving trigonometric equations

To solve trig equations, isolate the trig function first, then use known values on the unit circle or reference angles. Always check the domain and find all solutions within the required interval.

Example: sin x = 1/2 gives x = 30° + 360°k or x = 150° + 360°k.

4. Pre-Calculus

Equations of circles (center and radius)

The standard form of a circle with center (h, k) and radius r is:

(x - h)² + (y - k)² = r²

This formula is used to identify the center, radius, and graph of a circle from an equation.

Conic sections

Conic sections are curves formed by intersecting a plane with a cone. The major types are:

  • Circle: all points equidistant from a center
  • Parabola: set of points equidistant from a focus and directrix
  • Ellipse: sum of distances to two foci is constant
  • Hyperbola: difference of distances to two foci is constant

Their equations and key features are central in pre-calculus and calculus.

5. Differential Calculus

Limits and continuity

A limit describes the value a function approaches as x approaches a certain number. If the function approaches the same value from both sides, the limit exists.

Continuity means that the function has no breaks, jumps, or holes at that point. A function is continuous at x = a if the limit exists, the function is defined at a, and both are equal.

Application of derivatives

Derivatives measure rate of change. They help determine velocity, slope of a tangent, increasing and decreasing intervals, and optimization.

If f'(x) > 0, the function is increasing; if f'(x) < 0, it is decreasing.

Rules of differentiation

Common rules include:

d/dx (x^n) = n x^(n-1)
d/dx (c f(x)) = c f'(x)
d/dx (f ± g) = f' ± g'
d/dx (fg) = f'g + fg'
d/dx (f/g) = (f'g - fg') / g²

These rules are used to differentiate polynomial, rational, and product/quotient expressions.

Finding the slope and equation of a tangent line

The derivative at a point gives the slope of the tangent line to the curve there.

m = f'(a)

Then the equation of the tangent line at (a, f(a)) is:

y - f(a) = f'(a)(x - a)

Word problems on optimization (max/min) and related rates

Optimization problems ask for the largest or smallest value of a quantity. Usually, write the function, take the derivative, set it to zero, and test critical points.

Related rates problems connect how fast quantities change with respect to time. Differentiate the equation that relates the quantities and then substitute known values.
